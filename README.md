🦷 StomatMed — сайт стоматологической клиники

О проекте

StomatMed — веб-приложение стоматологической клиники, разработанное на Python с использованием Django.

Сайт предназначен для ознакомления с услугами клиники и взаимодействия пациентов с врачами.

Основные возможности

Просмотр информации о стоматологической клинике.

Просмотр категорий и услуг.

Просмотр информации о врачах.

Запись на приём к врачу.

Просмотр собственных записей.

Регистрация и авторизация пользователей.

Возможность оставлять отзывы.

Отправка вопросов администрации клиники по электронной почте.

Установка и запуск проекта

1. Клонирование репозитория

Открой терминал и выполни команду:

git clone https://github.com/OlenaTsysar/Final.git

Перейди в папку проекта:

cd stomatolog

2. Создание виртуального окружения

python -m venv venv

Активация виртуального окружения:

Windows:

venv\Scripts\activate

Linux / macOS:

source venv/bin/activate

3. Установка зависимостей

pip install -r requirements.txt

4. Применение миграций

python manage.py migrate

5. Запуск сервера разработки

python manage.py runserver

После запуска открой сайт в браузере:

http://127.0.0.1:8000/
